# 📊 Airbnb User Engagement & Booking Analysis Dashboard

An interactive Power BI dashboard designed to analyze user behavior, messaging patterns, traffic sources, and booking requests for Airbnb. This project provides key data insights into user journeys across different devices and months.

---

## 📌 Project Overview

This Power BI dashboard visualizes key metrics related to user activity on Airbnb, helping to identify trends in site traffic, booking conversion, and device preferences.

### 🔑 Key Metrics Analyzed:
* **Total Visitors:** 255
* **Total Messages:** 1.0K
* **Total Sessions:** 6.781K
* **Total Searchers:** 1.0K
* **Booking Requests:** 136

---

## 💡 Key Insights & Visualizations

1. **Device Distribution:** 
   * **iPhone - Web** dominates overall traffic with **35.12%** (497 users).
   * **iPhone - iOS** accounts for **26.08%** (369 users).
   * **Android Tablet - Web** contributes **16.68%** (236 users), followed by **Desktop - IE** at **14.35%** (203 users).

2. **Monthly Sales & Trends:**
   * Traffic and engagements peak around **September** and **December**, showing clear seasonal user interest.

3. **Message vs. Booking Trends:**
   * Visualizes the comparison between total user messages sent and actual booking requests completed per month.

4. **Booking Request Per Month:**
   * Line analysis tracking user conversion across months, peaking in **December (22 requests)** and **February (18 requests)**.
